================================================================
  다른 Linux 서버로 이전 및 테스트 절차

[ 옮길 디렉터리 ]

  gaia_ragas/      ← QA 생성 / RAGAS 평가 소스 코드 (.venv 제외)
  qdrant_rag/      ← Qdrant RAG 파이프라인 소스 코드 (.venv 제외)
  gaia_dataset/    ← DART 통합 데이터셋 (111GB, XML/PDF/XLS 원본)
  collector/       ← gaia_kr_collector(수집기) + eval(QA/RAGAS 생성) 소스 코드 (.venv 제외)
  gaia_web_dataset/ ← Web 수집 데이터셋 (약 50GB, PDF/DOCX/XLSX/PPTX 등, 73개 소스)

  ※ dataset1/, dataset2/, dataset3/ 는 gaia_dataset/ 으로 이미 통합됨 → 불필요
  ※ .venv/, qdrant_storage/, output/ 은 타겟에서 재생성
  ※ collector/gaia_kr_collector/config.yaml의 root_dir은 상대경로(../../gaia_web_dataset)라
    collector/와 gaia_web_dataset/를 같은 상대 위치(cohesity-poc/ 바로 아래)에 두면 그대로 동작함


[ 1. 파일 전송 (rsync 권장) ]

  rsync -avz --progress \
    /data/richard/cohesity-poc/gaia_ragas/ \
    /data/richard/cohesity-poc/qdrant_rag/ \
    /data/richard/cohesity-poc/gaia_dataset/ \
    /data/richard/cohesity-poc/collector/ \
    /data/richard/cohesity-poc/gaia_web_dataset/ \
    user@target-server:/data/cohesity-poc/

  ※ collector/ 전송 시 .venv/, gaia_kr_collector/logs/, gaia_kr_collector/.collect.pid,
    eval/output/ 은 제외해도 무방 (rsync --exclude 옵션 사용 가능, 타겟에서 재생성/재실행)

  ※ --progress: 진행률 표시
  ※ 중단 후 재실행하면 이어서 전송 (중복 전송 없음)


[ 2. 타겟 서버에서 환경 설정 ]

  # Python 3.10 이상 필요 — 이 저장소의 모든 가상환경(gaia_ragas/qdrant_rag/
  # collector/gaia_kr_collector/collector/eval)은 3.12로 통일되어 검증됨.
  # 타겟 서버에도 python3.12로 맞추는 것을 권장 (3.10+면 동작은 하나 미검증).
  python3 --version

  # gaia_ragas 가상환경
  cd /data/cohesity-poc/gaia_ragas
  python3 -m venv .venv
  .venv/bin/pip install --upgrade pip
  .venv/bin/pip install -r requirements.txt

  # qdrant_rag 가상환경
  cd /data/cohesity-poc/qdrant_rag
  ./run.sh setup

  # collector/gaia_kr_collector 가상환경 (Web 수집기 재개 시 필요)
  cd /data/cohesity-poc/collector/gaia_kr_collector
  ./run.sh setup   # venv 생성 + LibreOffice/h2orestart(HWP 변환 필터) 설치 확인

  # collector/eval 가상환경 (Web QA/RAGAS 생성 시 필요)
  cd /data/cohesity-poc/collector/eval
  python3 -m venv .venv
  .venv/bin/pip install --upgrade pip
  .venv/bin/pip install -r requirements.txt


[ 2-1. Web 수집 상태 확인 / 재개 (선택) ]

  cd /data/cohesity-poc/collector/gaia_kr_collector
  ./run.sh status          # 타입별 쿼터 진행률, manifest 기준 (전송 직후엔 원본 그대로 유지됨)
  ./run.sh bg               # 이어서 수집 (manifest.csv로 중복 다운로드 방지)

  # Web 데이터로 QA/RAGAS 데이터셋 생성 (LLM API 필요)
  cd /data/cohesity-poc/collector/eval
  export ANTHROPIC_API_KEY=sk-ant-...
  .venv/bin/python run_pipeline.py --step all


[ 3. Qdrant 인제스트 ]

  cd /data/cohesity-poc/qdrant_rag

  # 테스트 (특정 회사만, 빠름)
  ./run.sh ingest --company 삼성전자

  # 전체 인제스트 (시간 소요)
  ./run.sh ingest


[ 4. QA 생성 및 평가 ]

  export ANTHROPIC_API_KEY=sk-ant-...

  # [A안] 전체 랜덤 샘플링
  cd /data/cohesity-poc/gaia_ragas
  ./run.sh --step sample
  ./run.sh --step qa

  cd /data/cohesity-poc/qdrant_rag
  ./run.sh evaluate

  # [B안] 특정 회사 일치 (인제스트와 동일 회사)
  cd /data/cohesity-poc/gaia_ragas
  ./run.sh --step sample --company 삼성전자
  ./run.sh --step qa     --company 삼성전자
  # → output/qa_pairs_삼성전자.json 생성

  cd /data/cohesity-poc/qdrant_rag
  ./run.sh ingest   --company 삼성전자
  ./run.sh evaluate --company 삼성전자 --limit 20


[ 5. 동작 확인 ]

  # Qdrant 컬렉션 상태
  cd /data/cohesity-poc/qdrant_rag
  ./run.sh info

  # 벡터 검색 테스트
  ./run.sh search "삼성전자 2021년 영업이익"

  # RAG Q&A 테스트
  ./run.sh qa "LG화학 배터리 사업 분할 내용은?"
