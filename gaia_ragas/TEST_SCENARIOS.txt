[ 전제: 공시 문서가 Cohesity GAIA에 인덱싱 완료된 상태 ]
[ 평가 기준: Containment >= 0.5, RAGAS faithfulness >= 0.7 ]

TC-G-01  보고서 유형별 쿼리 — 사업보고서(A)
  질문 유형: 요약
  예시 질문:
    - "삼성전자의 2023년 사업보고서에서 주요 사업 부문은?"
    - "현대자동차의 최근 사업보고서 기준 종업원 수는?"
  검증:
    - GAIA 응답에 회사명 및 관련 키워드 포함
    - retrieved_contexts에 사업보고서 출처 포함
  목표: faithfulness >= 0.7

TC-G-02  보고서 유형별 쿼리 — 공정위공시(J)
  질문 유형: 관계 파악
  예시 질문:
    - "고려아연의 계열회사 간 주식소유 현황에서 서린상사의 지분율은?"
    - "영풍그룹 기업집단의 대표회사는?"
  검증:
    - 지분율, 계열사명 등 구체적 수치/명칭 포함
  목표: faithfulness >= 0.7

TC-G-03  보고서 유형별 쿼리 — 주요사항보고서(B)
  질문 유형: 사실 확인
  예시 질문:
    - "롯데쇼핑의 2021년 정정 계약서 공시의 정정 대상 공시서류는?"
    - "SK케미칼의 유상증자 결정 주요사항보고서에서 신주 발행 목적은?"
  검증:
    - 정정 내용, 결정 사항 등 핵심 팩트 포함
  목표: answer_relevancy >= 0.6

TC-G-04  재무제표 수치 쿼리 (XLS 기반)
  질문 유형: financial
  예시 질문:
    - "고려아연의 2014년 연결 재무상태표 기준 유동자산 총액은?"
    - "한국전력공사의 2023년 3분기 매출액은?"
    - "현대자동차의 직전 사업연도 대비 영업이익 증감은?"
  검증:
    - 수치 포함 응답 (억원 단위 또는 원 단위)
    - 기준 날짜 명시
  목표: faithfulness >= 0.8, exact_match 수치 일치

TC-G-05  기간별 쿼리 — 연도 범위 지정
  질문 유형: 사실 확인 + 시간 조건
  예시 질문:
    - "2021년에 제출된 기아의 공정위공시 내용은?"
    - "2015~2020년 사이 고려아연이 제출한 사업보고서 건수는?"
  검증:
    - 응답이 지정 기간 데이터 참조
    - 다른 연도 데이터 혼입 없음
  목표: context_precision >= 0.6

TC-G-06  회사별 쿼리 — 대기업 그룹
  예시 질문:
    - "한화그룹 계열사 중 DART에 공시된 회사 목록은?"
    - "삼성전자와 삼성생명의 공시 유형별 건수 비교"
  검증:
    - 그룹사 인식 및 연관 회사 응답
  목표: context_recall >= 0.5

TC-G-07  다중 문서 종합 쿼리
  질문 유형: 관계 파악 + 요약
  예시 질문:
    - "SK텔레콤의 공정위공시와 사업보고서에서 공통적으로 언급되는 계열사는?"
    - "현대모비스의 최근 3개년 영업이익 추이는?"
  검증:
    - 복수 문서 내용 종합
    - 출처 구분 명확
  목표: faithfulness >= 0.7, context_recall >= 0.6

TC-G-08  문서 유형 혼합 쿼리 (XML + PDF + XLS)
  질문 유형: 종합
  예시 질문:
    - "한국전력공사의 분기보고서에서 재무제표상 영업손실과 공시 본문의

  검증:
